# Brand assets

Drop the club's brand files here and they'll be picked up for the redesign:

- `logo/`: logo files (SVG preferred, otherwise high-res PNG), including any light/dark or icon variants
- `photos/`: event photography (JPG/PNG/WebP, the larger the better; they get optimised at build time)
- `brand.md`: brand colours (hex values) and font names, plus any usage rules
